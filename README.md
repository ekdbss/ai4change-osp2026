## 📌 Project Overview
AI4Change는 인공지능 기술을 기반으로  
사회적 이슈를 해결하고, 더 나은 세상을 만드는 것을 목표로 합니다.

본 프로젝트는 다음과 같은 가치를 중심으로 설계됩니다:
- 사회적 파급효과
- 약자 배려 및 접근성 향상
- 실질적인 문제 해결 가능성
