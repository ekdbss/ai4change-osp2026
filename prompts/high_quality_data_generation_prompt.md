# 고품질 학교 민원 데이터 생성 프롬프트

아래 프롬프트는 검수된 라벨 기준표를 바탕으로 KoBERT 학습 데이터를 카테고리별 300건 이상으로 확장할 때 사용한다.

## 기본 프롬프트

```text
너는 한국 학교 민원 데이터셋을 만드는 NLP 데이터 라벨링 전문가다.

목표:
KoBERT 기반 학교 민원 자동 분류 모델 학습용 synthetic data를 생성한다.

생성 대상 카테고리:
{category}

생성 개수:
{count}개

반드시 아래 JSON 배열만 출력하라.
설명, 마크다운, 코드블록은 출력하지 않는다.

[
  {
    "text": "민원 문장",
    "category": "{category}",
    "urgency": "낮음|보통|높음"
  }
]

공통 생성 조건:
- category는 반드시 "{category}"만 사용한다.
- text는 실제 학부모가 학교에 남기는 민원처럼 자연스럽게 작성한다.
- 개인정보, 학교명, 교사명, 학생명, 전화번호, 주소는 넣지 않는다.
- 욕설, 명예훼손, 과도한 비난 표현은 넣지 않는다.
- 한 문장은 30자 이상 180자 이하로 작성한다.
- 같은 문장 구조를 반복하지 않는다.
- 같은 단어 조합을 과도하게 반복하지 않는다.
- 단순 키워드 나열이 아니라 상황과 요청이 모두 포함되게 작성한다.
- 문체는 낮은 감정, 보통 감정, 강한 감정이 섞이되 모두 민원으로 접수 가능한 표현이어야 한다.

긴급도 분포:
- 낮음 25%
- 보통 50%
- 높음 25%

긴급도 기준:
- 높음: 사고, 다침, 폭력, 따돌림, 협박, 식중독, 알레르기, 파손 위험, 즉시 안전 확인이 필요한 사안
- 보통: 확인과 답변이 필요하지만 즉시 위험은 낮은 사안
- 낮음: 일정, 안내, 절차, 건의, 단순 문의 중심의 사안

카테고리 라벨 기준:

1. 수업/학습 문제
- 수업 내용, 과제, 평가, 시험, 진도, 설명 부족, 보충학습, 준비물 안내가 핵심이다.
- 교사가 언급되어도 핵심이 수업/평가/과제라면 이 라벨이다.

2. 교사 태도/행동
- 교사의 말투, 상담 태도, 차별, 학생 응대, 지도 방식, 학부모 소통 방식이 핵심이다.
- 수업 내용보다 교사의 언행과 관계 경험이 핵심이어야 한다.

3. 시설/환경
- 교실, 화장실, 냉난방, 조명, 책걸상, 창문, 운동장, 공사, 소음, 위생, 공기질 등 물리적 환경이 핵심이다.

4. 급식
- 급식 식단, 음식 온도, 위생, 알레르기 표시, 배식, 식중독 우려, 우유 제공 등 급식 운영이 핵심이다.

5. 생활지도/안전
- 학교폭력, 따돌림, 괴롭힘, 등하교 안전, 사고 위험, 쉬는 시간 지도, 운동장 안전, 생활지도 공백이 핵심이다.
- 안전 위험이 있으면 다른 카테고리보다 이 라벨을 우선한다.

6. 기타
- 행사, 일정, 행정 절차, 서류, 가정통신문, 방과후 과정, 상담 일정, 학교 운영 문의 등 위 카테고리에 명확히 속하지 않는 사안이다.

중요한 경계 사례:
- “선생님이 숙제를 많이 내주셨다”는 수업/학습 문제이다.
- “선생님 말투 때문에 학생이 위축되었다”는 교사 태도/행동이다.
- “급식실 바닥이 미끄럽다”는 시설/환경 또는 생활지도/안전 중 위험성이 핵심이면 생활지도/안전이다.
- “알레르기 표시가 부족하다”는 급식이며 긴급도는 높음일 수 있다.
- “행사 일정 안내가 부족하다”는 기타이다.

기존 데이터와 중복되거나 너무 비슷한 문장은 만들지 말라.
아래 예시와 표현 구조가 겹치지 않도록 변형하라.

기존 예시:
{examples}
```

## 권장 생성 방식

- 한 번에 300건을 만들지 말고 카테고리별로 50건씩 나누어 생성한다.
- 생성 후 사람이 10-20%를 빠르게 검수한다.
- 중복 문장은 제거한다.
- `text,category,urgency` 컬럼으로 저장한다.

## Colab 학습 권장 명령

```bash
python scripts/prepare_training_data.py
python model/train_kobert.py --epochs 6 --batch-size 16 --max-length 128
python model/evaluate.py
```

GPU 메모리 오류가 나면:

```bash
python model/train_kobert.py --epochs 6 --batch-size 8 --max-length 128
```
