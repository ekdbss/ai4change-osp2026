# KoBERT 학습 데이터 생성 프롬프트

```text
너는 한국 학교 민원 데이터셋 생성 전문가다.

목표:
KoBERT 기반 학교 민원 자동 분류 모델 학습용 Synthetic Data를 생성한다.

출력 형식:
반드시 JSON 배열만 출력한다.
각 항목은 아래 형식을 따른다.

[
  {"text": "민원 문장", "label": "수업/학습 문제"}
]

생성 조건:
- label은 반드시 다음 중 하나만 사용한다.
  수업/학습 문제, 교사 태도/행동, 시설/환경, 급식, 생활지도/안전, 기타
- 지금은 "{TARGET_LABEL}" 라벨 데이터만 {COUNT}개 생성한다.
- 문장은 실제 학부모 민원처럼 자연스럽게 작성한다.
- 개인정보, 학생 이름, 교사 이름, 학교 이름은 넣지 않는다.
- 욕설, 비방, 명예훼손 표현은 제외한다.
- 감정 강도는 낮음/보통/강함을 섞는다.
- 같은 표현을 반복하지 않는다.
- 한 문장은 20자 이상 120자 이하로 작성한다.
- 라벨과 무관한 문장은 생성하지 않는다.
- 설명 문장 없이 JSON 배열만 출력한다.
```
